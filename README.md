# Voice Control

Голосовой помощник для Windows. Говорите — компьютер понимает.

Управляйте музыкой, создавайте напоминания, открывайте браузер, добавляйте задачи и задавайте вопросы ИИ — всё голосом.

## Что умеет

**Музыка и медиа**
- «Алиса, громче» / «пожалуйста, тише» — регулятор громкости
- «Алиса, пауза» / «стоп» — поставить на паузу или остановить
- «Алиса, открой YouTube» — открыть браузер и перейти на YouTube

**Напоминания**
- «Алиса, напомни через 30 минут позвонить маме»
- «пожалуйста, напомни завтра в девять собрать портфель»
- Напоминания создаются как события в Google Calendar

**Задачи**
- «Пожалуйста, добавь задачу купить хлеб»
- «Алиса, заверши задачу купить хлеб» — зачёркивает выполненное

**Планы**
- «Алиса, что у меня по планам?» — расскажет о ближайших событиях

**Вопросы ИИ**
- «Алиса, какой сегодня день?» — ответ озвучивается голосом
- «Пожалуйста, переведи hello world на русский» — ИИ отвечает вслух

**Прерывание**
- В любой момент скажите «стоп» или «хватит» — помощник замолчит

**Обучение**
- «Алиса, запомни ютюб — это openyoutube» — запоминает ваши коверканья
- «Пожалуйста, забудь ютюб» — удаляет запомненную фразу

## Как пользоваться

### Триггеры

Перед любой командой назовите помощника:
- **«Алиса»** — основной вариант
- **«Пожалуйста»** — альтернатива

Можно ставить триггер в любом месте:
- «Алиса, сделай громче» ✓
- «Сделай громче, пожалуйста» ✓
- «Громче, Алиса» ✓

### Структура фразы

```
[триггер] + действие + [настройка]
```

| Пример фразы | Что происходит |
|--------------|----------------|
| «Алиса, громче» | Повышает громкость |
| «Алиса, громче немного» | Повышает чуть-чуть |
| «Алиса, громче сильно» | Повышает значительно |
| «Алиса, тише» | Снижает громкость |
| «Алиса, пауза» | Ставит на паузу |
| «Алиса, напомни через час приготовить ужин» | Создаёт напоминание |
| «Алиса, добавь задачу купить молоко» | Создаёт задачу |
| «Алиса, по планам» | Рассказывает о расписании |
| «Алиса, какой сегодня день?» | ИИ отвечает голосом |

### Настройки громкости

- **«немного»** — уменьшает шаг в два раза
- **«сильно»** — увеличивает шаг в два раза (6% → 12%)

### Браузер

Команда «Алиса, открой YouTube» запускает браузер и переходит на YouTube. Управление вкладками, клики и поиск на YouTube доступны через голосовые команды.

## Настройка команд

Команды хранятся в `targets/<имя_компьютера>/commands.json`.

Чтобы добавить новую команду:

1. Узнайте имя вашего компьютера: `hostname` в консоли
2. Откройте `targets\<hostname>\commands.json`
3. Добавьте запись в секцию `commands` — имя команды и действие
4. Добавьте варианты произношения в `match`
5. Перезапускать программу не нужно — конфиг подхватится сам

Пример: добавляем команду «открой VK»:

```json
{
    "commands": {
        "openvk": "start https://vk.com"
    },
    "match": {
        "openvk": ["открой ВК", "открыть вконтакте", "загрузи вк"]
    }
}
```

Для сложных команд (составных, с условиями) смотрите `STRUCTURE.md`.

## Запуск

```bash
python main.py
```

Программа:
1. Скачает модель распознавания речи (~50 МБ) при первом запуске
2. Начнёт слушать микрофон
3. Озвучивает ответы голосом (каскад: интернет-синтез → локальный → системный)
4. Введите `Enter` для выхода

### Требования

- Windows 10/11, Python 3.11+
- Микрофон
- Интернет для ИИ и синтеза речи

### Установка

```bash
# Виртуальное окружение
conda create -n voice python=3.11 -y && conda activate voice

# Зависимости
pip install -r requirements.txt
```

### Воспроизведение звука

Windows: скопируйте `mpg123.exe` в `bin/mpg/`.  
Linux: `sudo apt install mpg123 libportaudio2`  
macOS: `brew install mpg123 portaudio`

### Автозапуск

Программа может запускаться автоматически через Resurrector — настройте в его конфиге.

## Что внутри

```
voice/
├── main.py              # Точка входа: слушает микрофон, обрабатывает команды
├── targets/             # Конфигурация: команды, алиасы, статусы
├── lib/                 # Библиотека: команды, календарь, задачи, TTS, провайдеры
├── bin/                 # Вспомогательные скрипты
├── prompts/             # Промпты для ИИ
├── models/              # Модели распознавания речи
├── .opencode/           # Скиллы-дубли (для opencode-агента)
└── tests/               # Тесты
```

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Команда не срабатывает | Убедитесь, что произнесли триггер («Алиса» / «Пожалуйста») |
| «[Blocked]» в консоли | Посмотрите логи статуса — вероятно, не выполнено условие (нет VPN, не играет музыка) |
| ИИ не отвечает | Проверьте OmniRouter и LM Studio — они должны быть запущены |
| Кракозябры в консоли | Это нормально для русской Windows, программа переключает кодировку на лету |
| Нет голоса | Убедитесь, что `mpg123.exe` в папке `bin/mpg/`, проверьте громкость Windows |
| Напоминания не создаются | Запустите авторизацию Google — откроется браузер для согласия |
