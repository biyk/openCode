# Команды ↔ скиллы

Соответствие команд `commands.json` скиллам `cli/.opencode/skill/`.
Обозначения вызова: `[ключ]` — триггер (`алиса`, `пожалуйста`),
`_команда_` — слово после ключа (совпадение ≥90% с match-шаблоном),
`{настройка}` — слова после команды.

## Свободный текст (`{{text}}`)

Команды `calendar-reminder` и `task-add` принимают свободный текст —
все слова после команды подставляются в `{{text}}` shell-шаблона:

```
[Алиса] _напомни_ {через тридцать минут} {сходить в магазин}
```

- опция 1 — время/период текстом (`через тридцать минут`);
  если время не детектировано — напоминание на **+60 минут**;
- опция 2 — текст мероприятия (`сходить в магазин`).
- shell: `python -m lib.reminders "{{text}}"` →
  `ReminderHandler` + `GoogleCalendar.create_reminder`.

```
[пожалуйста] _создай задачу_ {Убраться у кошки}
```

- одна опция — текст задачи (`Убраться у кошки`).
- shell: `python -m lib.tasks create "{{text}}"` →
  `TaskHandler` + `GoogleTasks.create_task` (список `@default`).

```
[Алиса] _анализ_ / _диагностика_ / _проверь логи_
```

- без опций (или фокус текстом после команды).
- shell: `python -m lib.diagnose launch "{{text}}"` — мгновенный возврат:
  detached-супервизор (`lib/diagnose.py run`) в фоне.
- супервизор: путь последнего `logs/commands_*.log` + хвост +
  последние сообщения чата → задача агенту opencode (raw, корень репо):
  «проанализируй, найди и исправь ошибки», протокол WORKING.MD
  (создать → отмечать статус → удалить).
- правила: грязный `git status` — только озвучка
  «Сначала зафиксируй изменения в гит», запуска нет;
  WORKING.MD не правится >600с — прибить агента,
  `git checkout -- .`, заново (до 5 попыток);
  WORKING.MD пропал — прогон `pytest tests/ -q`: зелёные — финиш,
  красные — откат + задача назад агенту (хвост ошибок в промпте).

Настройки громкости: `{немного}` — шаг ×0.5, `{сильно}` — шаг ×2.
